## 🎯 About

This repository serves as a museum of coding interview problems, featuring:
- **DSA Fundamentals**: Core data structures and algorithms
- **LeetCode Problems**: Popular interview questions
- **GeeksforGeeks (GFG)**: Classic DSA problems
- **Codeforces**: Competitive programming challenges

All solutions aim for **O(n) time complexity** or better, focusing on optimal approaches.

## 🚀 How to Use

1. **Browse by Category**: Navigate to the relevant folder (DSA, LeetCode, GFG, or Codeforces)
2. **Select a Problem**: Each problem includes:
   - Problem statement
   - Approach explanation
   - Time & Space complexity analysis
   - Solution code
3. **Learn the Pattern**: Focus on understanding the O(n) approach

## 🤝 Contributing

Contributions are welcome! Please ensure:
- Solutions maintain O(n) or better time complexity
- Code is well-commented
- Problem statements are clear
- Complexity analysis is included

## 📊 Complexity Focus

This repository emphasizes **efficient solutions**:
- ✅ O(1) - Constant time
- ✅ O(log n) - Logarithmic time
- ✅ O(n) - Linear time
- ⚠️ O(n log n) - When O(n) isn't achievable
- ❌ Avoid O(n²) or worse unless necessary
